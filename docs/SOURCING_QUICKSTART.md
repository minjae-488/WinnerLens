# 도매 소싱 자동화 - 빠른 시작 가이드

## 🎯 무엇을 하는 기능인가요?

**키워드 하나로 도매 상품 발굴부터 쿠팡 등록까지 자동화!**

```
키워드 입력 ("무선 이어폰")
    ↓
1866/도매매에서 최저가 검색
    ↓
AI가 쿠팡 리스팅 자동 생성
    ↓
원가 계산 + 추천 판매가 제시
    ↓
사용자 확인/수정
    ↓
쿠팡에 원클릭 등록 ✅
```

---

## ⚡ 핵심 가치

### 기존 방식의 문제점
❌ 도매 사이트 일일이 검색 (2-3시간)  
❌ 수동으로 가격 비교 및 계산  
❌ 상세페이지 직접 작성 (30분/건)  
❌ 마진 계산 실수로 손해  

### WinnerLens 솔루션
✅ **자동 검색**: 1866, 도매매 동시 크롤링 → 최저가 자동 발굴  
✅ **AI 생성**: Google Gemini가 쿠팡 리스팅 자동 작성  
✅ **가격 최적화**: 3가지 전략 추천 (공격적/균형/프리미엄)  
✅ **원클릭 등록**: 검수 → 등록까지 자동화  

**⏱️ 소요 시간: 3시간 → 10분 (95% 단축!)**

---

## 🚀 사용 방법

### 1단계: 키워드 검색
```
대시보드 → 도매 소싱 → 키워드 입력
예: "무선 이어폰", "USB 케이블", "핸드폰 케이스"
```

### 2단계: 최저가 상품 선택
```
검색 결과에서 원하는 상품 클릭
- 가격 비교
- 이미지 확인
- 최소 주문 수량 체크
```

### 3단계: AI 리스팅 생성
```
자동 생성됨:
- 상품명 (SEO 최적화)
- 상세 설명 (HTML)
- 주요 특징 (불릿 포인트)
- 스펙 테이블
- 고시정보

→ 필요시 수정 가능!
```

### 4단계: 가격 계산
```
입력:
- 도매가: 10,000원
- 수량: 10개
- 배송비: 3,000원
- 목표 마진: 30%

출력:
- 개당 원가: 1,300원
- 추천 판매가:
  • 공격적: 18,500원 (마진 25%)
  • 균형: 21,000원 (마진 32%) ⭐ 추천
  • 프리미엄: 23,500원 (마진 38%)
```

### 5단계: 가격 선택 & 등록
```
추천가 선택 또는 직접 입력
→ "쿠팡에 등록하기" 클릭
→ 자동 검수 → 등록 완료! 🎉
```

## 💡 실전 예시

### 예시 1: 무선 이어폰 소싱

**입력:**
- 키워드: "블루투스 이어폰"
- 사이트: 1866

**결과:**
```
최저가 상품 발견:
- 상품명: TWS 블루투스 이어폰 5.0
- 도매가: 8,900원
- 최소 주문: 10개
```

**AI 생성 리스팅:**
```
상품명: [무선 블루투스 5.0] TWS 이어폰 고음질 통화 노이즈캔슬링 방수 IPX7

상세 설명:
🎧 프리미엄 음질
- 블루투스 5.0 칩셋
- AAC 코덱 지원
- 노이즈 캔슬링

💧 생활 방수 IPX7
🔋 최대 24시간 재생
📦 구성품: 이어폰, 충전 케이스, 이어팁 3종
```

**가격 계산:**
```
원가:
- 도매가: 8,900원 × 10개 = 89,000원
- 배송비: 3,000원
- 총 원가: 92,000원
- 개당 원가: 9,200원

추천 판매가:
- 공격적: 16,900원 (마진 28%)
- 균형: 19,900원 (마진 35%) ⭐
- 프리미엄: 22,900원 (마진 41%)

→ 균형 전략 선택: 19,900원
```

**결과:**
- 등록 성공! ✅
- 예상 순이익: 10,700원/개 × 10개 = 107,000원

## 🛠️ 기술 스택

### 백엔드
- **크롤링**: Puppeteer (동적 페이지), Cheerio (HTML 파싱)
- **캐싱**: Redis (1시간 TTL)
- **AI**: Google Gemini 1.5 Flash
- **데이터베이스**: PostgreSQL (Prisma ORM)

### 프론트엔드
- **프레임워크**: Next.js 14
- **상태 관리**: Zustand
- **UI**: React + Tailwind CSS

## 🚨 주의사항

### 법적 준수
✅ **robots.txt 준수**: 크롤링 허용 범위 내에서만 동작  
✅ **Rate Limiting**: 초당 최대 2 요청 (서버 부하 방지)  
✅ **개인정보 보호**: 사용자 데이터 암호화 저장  

### 사용 제한
- 크롤링 결과는 **참고용**이며, 최종 확인은 사용자 책임
- 도매 사이트 정책 변경 시 일시적 오류 가능
- AI 생성 콘텐츠는 **반드시 검토 후 사용**
