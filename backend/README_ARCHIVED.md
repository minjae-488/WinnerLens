# Backend 폴더 (아카이브)

이 폴더는 프론트엔드와 백엔드가 통합되기 전의 백엔드 코드입니다.

## 통합 완료

2025-12-29: 백엔드 기능이 Next.js API Routes로 완전히 통합되었습니다.
모든 백엔드 코드는 `frontend/` 폴더로 이동되었습니다.

## 현재 상태

- ✅ 모든 API는 `frontend/app/api/` 에 있습니다
- ✅ 서비스 로직은 `frontend/src/services/` 에 있습니다
- ✅ Prisma 설정은 `frontend/prisma/` 에 있습니다

이 폴더는 참고용으로 보관되며, 더 이상 사용되지 않습니다.
